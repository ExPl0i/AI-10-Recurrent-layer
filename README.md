# Рекуррентные слои: РНС, LSTM, GRU

Занятие курса «Искусственный интеллект» для 10 класса (практическая работа №1, часть 5Р). Ученики пишут рекуррентную ячейку на «голых» тензорах и сверяют ее с `nn.RNN`, на числах видят, почему простая рекуррентная сеть «забывает» начало последовательности, сравнивают ее с LSTM и применяют рекуррентные сети к временному ряду и к тексту.

## Теория (презентация)

1. **Развертка во времени** – последовательности, ячейка с памятью, затухание импульса, общие веса на каждом шаге, четыре схемы задач.
2. **Обучение и проблемы** – обратное распространение во времени (BPTT), затухающий градиент, отсечение градиента против взрыва.
3. **LSTM и GRU** – три вентиля LSTM, накопление памяти добавкой, GRU с двумя вентилями, сильные и слабые стороны.
4. **Пишем РНС на Python** – веса `nn.RNN` и `nn.LSTM`, план практики.

## Практическая работа

Сквозной пример – одномерная сеть $h_t = \tanh(0{,}5\,h_{t-1} + x_t)$ с одиночным импульсом на входе. Затем три задачи: запомнить первый символ, предсказать зашумленную синусоиду, сгенерировать текст по одной букве.

1. Шаг и проход рекуррентной сети.
2. Сверка с `nn.RNN`.
3. Как затухает градиент.
4. Запомнить первый символ: РНС против LSTM.
5. Прогноз зашумленной синусоиды.
6. Символьная модель текста.

Задания повышенной сложности: ячейка LSTM на тензорах со сверкой с `nn.LSTM`, отсечение градиента и график его нормы, вариант с `nn.GRU`.

**Правило работы:** в заданиях Р1–Р3 – только операции тензоров (`@`, `+`, `torch.tanh`, `torch.stack`, срезы), `nn.RNN` лишь для сверки в Р2. Начиная с Р4 – готовые `nn.RNN`, `nn.LSTM`, `nn.Linear` и оптимизаторы.

## Как работать

1. Откройте ноутбук в Jupyter или Google Colab.
2. В ячейках с заданиями замените `...` своим кодом (подсказка – в комментарии `# <--`).
3. Сверьте результат с ожидаемым; для обученных сетей указан порог. Ячейки обучения выполняются до минуты.

## Требования
